# 功能列表

本文描述当前 1.0.0 实现；不包含尚未开发的规划功能。

## 对话与身份

| 能力 | 当前行为 |
| --- | --- |
| 飞书私聊 | 每个应用独立与一位所有者配对；未授权私聊不执行任务 |
| 群聊 | 所有者首次 @ 启用该群，之后群成员可以 @ 使用 |
| 多应用、多群 | 一个服务连接多个飞书应用；每个应用独立凭证、配对与状态 |
| 话题回复 | 话题内触发的回复、进度和图片按原消息投递到话题内部 |
| 发送者识别 | 携带发送者 ID、类型与可获取的名称；未知姓名不猜测 |
| 上下文隔离 | 按应用、私聊／群聊和话题隔离历史与模型线程；同群共享上下文 |
| 引用消息 | 尝试取回同会话原消息，支持引用文字和图片；受资源访问权限限制 |
| 图片理解 | 支持直接图片、图文消息，以及显式要求查看的群历史图片 |
| 文件与表情 | 私聊接收文件；并非所有格式都可解析。表情可携带描述／标识，动态贴纸不保证视觉理解。群聊拒绝独立文件附件 |

群历史图片查询最多检查请求之前的 150 条消息，并受话题、发送者和飞书可访问范围限制。它不是完整历史媒体库，也不能保证取回任意久以前的图片。

## 人设与记忆

- 配置中心独立编辑名字、性格、习惯、语气、群聊规则与最近上下文条数（2 至 100）。
- 可选择每次请求读取本机 `~/.codex/AGENTS.md` 作为基础人设；配置中心补充对应偏好，权限规则始终优先。通用模板默认不继承。
- **Slo Memory**：本地 SQLite 保存提取事实、来源、会话摘要和相关轮次数据。由模型理解明确的记忆、更正、忘记要求，再调用受控工具。
- 每次普通聊天请求先在当前范围检索相关事实与摘要；模型还可主动调用 `search_memory`。当前是关键词匹配排序，没有向量数据库或 embedding。
- 非所有者的记忆写入成为候选，不作为已确认事实召回；当前界面没有候选审批列表。
- 每 10 轮完整对话或约 8000 字后台生成摘要，失败时保留旧摘要。
- 界面可选群／私聊和话题查询记忆，不默认列出全部记忆。Mem0 仅作为禁用选项，尚未接入。
- **背景知识**由用户维护，分「仅私聊」和「私聊与群聊均可用」，不被自动摘要覆盖，每区最多 20000 字符。

## 工具与输出

| 能力 | 说明与边界 |
| --- | --- |
| 天气 Skill | Open-Meteo 城市天气与最多 7 天预报，需要服务端网络可达 |
| 本地文件 Skill | 列出、搜索、读取 `workspace/` 内文本，拒绝越界路径与外部符号链接 |
| 文件写入与附件 | 私聊开启本地读取及写入权限后可写 workspace 文本、生成 artifacts 文本附件并发送；群聊可另行开启 workspace 文本写入，但不开放文件执行 |
| 飞书文档 Skill | 创建、读取、追加文档；按权限与文档／文件夹白名单控制。同会话创建的文档持久登记 |
| 文档素材 | 下载获准文档内存在的素材；私聊可插入受限本地图片。当前优先支持 `/docx/` 文档链接 |
| 画图并发送 | 可分别对私聊、群聊启用，专用 Codex worker 生成后自动上传；每次请求一张，生成阶段最长 480 秒 |
| 富文本 | 需要格式的 Markdown 及长文本转为飞书富文本；普通短文本直接发送，不保证完整 CommonMark 渲染 |
| 交互式卡片 | 可展示结果、最多 6 项选择、文本输入与最多 3 个 HTTPS 跳转按钮；选择和输入校验点击者、会话、原卡片，回调一次性消费 |
| 长任务进度 | 模型可主动报告真实阶段；普通聊天另有超时等待提示，不提供虚构百分比 |
| 真实 @ | 根据本群已识别身份提及成员或白名单机器人，不猜 ID，不支持 @ 所有人 |

Skill 是随源码提供的六个专用说明与受控工具，不是插件市场；当前界面不能安装、选择任意第三方 Skill。主模型不继承桌面全局插件，不具备任意本地命令执行能力。

## 排队、互聊与定时任务

- 同一会话串行处理，最多等待 20 条；不同会话全局最多同时处理 3 个。
- `/status` 查看状态与排队数量，`/stop` 取消当前及此前排队请求，`/new` 清空近期会话和模型线程。
- 可允许白名单机器人在已启用群明确 @ 后对话，使用持久化累计轮次与冷却限制防止无限互聊。真人再次 @ 可开启新轮。
- 定时任务支持固定消息或 AI 任务，每天／工作日／周一，可启用、暂停、立即运行、删除及选择主动 @ 对象。
- 每任务保留最近 50 次执行记录；电脑离线错过超过 5 分钟则跳过，不集中补发。同任务不重叠，不自动重试失败任务。
- 通用定时 AI 任务可检索当前范围记忆并使用获准只读工具，按条件决定发送或静默；不带完整聊天历史，不开放浏览器、写入、图片生成或递归创建任务。
- 已配对所有者可通过聊天创建、查询、暂停、恢复和取消当前会话/话题的通用任务，支持五字段cron、IANA时区、一次性时间和有效期。基础天气卡片使用Asia/Shanghai窗口，美国天气及山火卡片使用任务指定时区。
- macOS LaunchAgent 支持登录自启和进程退出后拉起；不能唤醒关机或睡眠的电脑。

## 配置中心与可观测性

七个页面：性格与习惯、记忆与知识、权限边界、Skill 与工具、定时任务、飞书接入、运行日志。支持手机窄屏布局；切换页面和后台刷新保留当前页面内未保存输入，浏览器重新加载不会保留草稿。

运行日志目前仍是最近服务事件列表，支持应用筛选、异常筛选、自动刷新及展开失败原因；读取最近 256 KB，最多展示 150 条。尚未实现按一次请求串联完整上下文、记忆检索与工具结果的详细追踪，也不展示模型内部思考过程。

## 试用边界

- 当前验证环境为 macOS；其他系统可自行尝试前台运行，但没有 Linux systemd 或 Windows 服务安装器。
- 使用 Codex SDK，尚无独立 Claude、其他云模型或本地模型适配器。修改模型名也必须是本机 Codex 账号支持的型号。
- 画图能力取决于账号、模型与所装 Codex CLI 的实际工具支持，不承诺所有账号都可用。
- 卡片真正可点击，依赖飞书后台正确订阅 `card.action.trigger`；代码测试不能替代接收者自己租户的端到端验证。
- 本机配置中心只绑定回环地址，不是带用户登录和角色系统的企业管理后台。不要直接开放到公网或多人共享主机。
